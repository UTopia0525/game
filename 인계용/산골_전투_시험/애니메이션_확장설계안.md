# 전투 애니메이션·무기 교체 확장 설계안

사용자 검토 전 제안이다. 이번 작업에서 이 범용 체계를 구현하거나 기존 무공·장비 수치를 변경하지 않았다.

## 권장 분리

| 구분 | 책임 | 포함하지 않는 것 |
|---|---|---|
| 전투 판정 | 현재Clock/Rules·무공 데이터가 비용·출수·회수·위치·범위·피해를 결정 | 이미지 모양·프레임 수로 명중 판정 |
| 동작 | 캐릭터 체형·무기 계열·행동·방향에 맞는 자세와 프레임 | 실제 장비의 위력·내기 비용 |
| 장비 외형 | 실제 무기ID의 검·도·창·검집 PNG와 크기 | 무공 동작 전체를 무기마다 다시 그리기 |
| 효과 | 참격·바람·장풍·잔상·피격 표시 | 효과가 닿아 보인다는 이유로 피해 추가 |

캐릭터마다 몸체/복식 동작 프로필을 두고, 같은 무기 계열 안에서 여러 장비 그림을 교체한다. 검·도·창·맨손은 자세가 다르므로 한 동작에 무기 그림만 바꿔 모든 계열을 처리하지 않는다. 같은 체형군의 동작은 재사용하되 어린이·큰 체격·굽은 자세는 별도 프로필이 필요하다.

## 필요한 제작 데이터
- 캐릭터 동작: `캐릭터 프로필 + 무기 계열 + 행동/무공ID + 방향 → 동작 클립`.
- 클립: 프레임 배열·등록점·손/검집 부착점·가림 순서·단계(출수/발동/회수) 표시.
- 장비: 실제 장비ID·계열·분리 PNG·자루를 쥐는 기준점·기준 크기·검집 유무.
- 무공 표시: 기존 무공ID를 유지하고 동작/효과ID만 연결한다. 위력·비용·범위·시간을 표시 데이터에 복제하지 않는다.
- 부착점·크기·프레임은 실제 원화 측정 전까지 null이다. 임의 좌표를 확정하지 않는다.

예를 들어 `samjae`는 검 계열 삼재 동작을 선택하고 현재 장비ID에 해당하는 검·검집을 붙인다. 같은 동작에서 정련검과 다른 검은 별도 장비 그림으로 구별한다. 실제 장비 그림과 측정값은 아직 만들지 않았다.

## 손·검집·가림
1. 기존처럼 검집은 인물 자신의 왼쪽 허리, 손에 든 검은 오른손 기준을 유지한다. 방향별 화면 좌우와 인체 좌우를 혼동하지 않는다.
2. 각 프레임의 손/허리 부착점에서 장비를 따라 움직이게 한다. 무기를 늘이거나 휘어서 손에 맞추지 않는다.
3. 방향·자세별로 뒤쪽 장비/몸체/무기/앞쪽 손 가림 순서를 지정한다. 항상 무기를 몸 앞에 덧그리는 방식만 쓰면 먼 손과 쥔 손가락이 잘못 보인다.
4. 검집·옷깃 때문에 좌우반전만으로 반대 방향을 만들지 않는다. 없는 방향을 잘못된 반전으로 자동 대체하지 않는다.

현재 전투 PNG에는 몸과 무기가 함께 그려져 있다. JSON이나 코드만 추가해서 임의 무기를 바로 교체할 수는 없다. 분리형으로 옮길 때 무기를 제거한 몸체 원화·별도 무기/검집·손 가림 레이어를 제작하고 검토해야 한다. 현재 원화는 그 전까지 통합형 시험 자료로 유지한다.

초기는 PNG시트와 프레임별 부착점으로 시작할 수 있다. 나중에2D리깅을 쓰더라도 몸체 재생부만 교체하고 무공ID·장비ID·부착점·전투 사건 연결은 유지하는 방향을 추천한다. 이번에 리깅이나 범용 애니메이션 시스템을 새로 만들지는 않았다.

## 엔진 사건과 애니메이션 연결
- `started`: 행동 토큰·무공ID·방향·장비 외형을 묶고 출수 표시를 시작한다.
- `effect`: 실제 엔진 결과에 따라 공격/빗나감/피해/회복 효과를 표시한다. 보여주기용 프레임이 먼저 끝나도 효과를 앞당기지 않는다.
- `moved`/`forced_move`: 엔진이 결정한 출발/도착 위치를 표시한다. 동작 파일의 자체 이동량을 논리 좌표에 다시 더하지 않는다.
- `ready`: 회수 끝을 반영한다. 프레임 수를 줄여 다음 행동을 일찍 허용하지 않는다.
- `dead`/`cancelled`/`finished`/재시작: 해당 표시를 정리한다. 화면 취소가 논리 비용 환불이나 새로운 무적 규칙을 만들지 않는다.
- 표시 식별자는 `교전 인스턴스 + 행동 토큰`으로 묶는 것을 추천한다. 재시작 때 토큰 번호가 다시 시작해도 이전 연출이 새 교전에 섞이지 않게 한다.

전투 중 무기 교체 허용 시점·시간·비용은 별도 게임 규칙 결정 사항이다. 이번에는 기능을 추가하지 않는다. 표시 체계에서는 한 행동이 시작될 때 선택한 외형을 그 행동 동안 유지하는 방식을 추천한다.

## 무공별 확장
기본 이동은 낮은 도약,추풍은 돌진,청풍은 전진 후 공격,유수는 공격 후 후퇴처럼 기존 판정의 이동 성격에 맞춰 다른 표시를 연결한다. 모든 이동을 같은 점프로 바꾸지 않는다. 동작이 누락되면 중립 자세 등 명시한 임시 표시와 누락 상태를 쓰고, 다른 무기 동작이나 다른 무공으로 몰래 대체하지 않는다.

선택 대기의 호흡은 표시용 실제 시간,공격의 출수·발동·회수는 논리 단계와 연결한다. 현재 수동 사건 진행 시험은 판정 후 잠깐 표시를 재생하는 방식이다. 향후 자동 시간 진행에 연결할 때는 표시 재생 시계와 논리 시계의 대응을 정리해야 하며 현재0.46초를 모든 무공의 실행 시간으로 사용하지 않는다.

## 권장 제작 순서
낮은 이동 느낌 검토 → 검 기본 자세의 몸/검/검집 분리1세트 → 기본공격·방어에서 부착·가림 확인 → 삼재검법1종의 출수/발동/회수 연결 → 같은 검 계열 확장 → 도·창·맨손의 별도 동작 제작.

최초1세트에서는 새 검사와 실제 표시로 손과 자루의 연결,검집 쪽,장비ID 변경,재시작 정리,판정 시각 불변을 확인한다. 전체 캐릭터·무공·장비 조합을 한 번에 제작하지 않는다.
