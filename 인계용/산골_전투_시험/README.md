# 산골 전투 시험 — 임시 인계

CLI 전달 및 로컬 플레이를 위한 임시 폴더입니다. 인계 완료 후 이 폴더를 삭제할 예정이며 자동 삭제하지 않습니다. 정식 전투 자료는 저장소의 `전투/`에 별도로 보관합니다.

## 다운로드 및 실행
1. `mountain_combat_godot.zip`을 다운로드하고 압축을 풉니다.
2. `산골전투_시험프로젝트/project.godot`를 Godot4.6 이상에서 가져옵니다.
3. 파일 가져오기가 끝나면 F5를 누릅니다.
4. 적 예고 확인 → 행동·방향 선택 → 행동 확정 → 다음 사건 순서입니다.

최신 화면개선 v2입니다. 가로·세로 정렬7×5 격자, 전투 영역 약82%, 전투 기록 비표시를 적용했습니다. 기존 수치는 유지했습니다. 별도 시험 프로젝트이며 본게임에 덮어쓰지 않습니다.

## CLI 인계
- `mountain/main.gd`: 화면 구성·시험 편성·산적 고정 행동.
- `mountain/battle_board.gd`: 전장과 원화 표시.
- `prototypes/timed_combat/combat_catalog.json`: 행동·무공·장비 수치.
- 같은 폴더의 `combat_clock.gd`, `combat_rules.gd`: 시간축·판정 규칙.
- `tests/mountain_smoke.gd`: 전용 연결 검사.

실제 Godot4.6.3에서48항목 통과한 프로젝트를 변경 없이 포장했습니다. 이번 임시 등록에서는 ZIP 무결성을 확인했으며 게임 검사를 재실행하지 않았습니다. 정식 AI·전 방향 공격 애니메이션·저장·퀘스트·본게임 통합은 미구현입니다. ZIP은 독립 스냅샷이며 정식 `전투/무공/` 데이터와 자동 동기화하지 않습니다.
