# 산골 전투 시험 — 임시 인계 v5

CLI 전달·플레이용 임시 폴더다. 인계 완료 뒤 삭제할 예정이며 자동 삭제하지 않는다. 정식 자원은 `전투/`에 별도로 둔다.

## 다운로드·실행
`mountain_combat_godot.zip`을 받아 별도 폴더에 풀고 `산골전투_시험프로젝트/project.godot`를 Godot4.6 이상에서 가져온 뒤F5. 기존 본게임이나 CLI에서 수정 중인 프로젝트에 통째로 덮어쓰지 않는다.

적 예고 확인 → 행동·방향 선택 → 행동 확정 → 다음 사건. B키는 대기 호흡 켜기/끄기다.

## 최신 반영
- v2: 7×5 직교 격자·전투 영역 약82%·전투 기록 비표시.
- v3: 도원·산적 대기 호흡. 머리·몸통·무기 크기 관계와 발밑 고정.
- v5: 낮고 빠른 이동. 준비0.06+공중0.30+착지0.10=0.46초,높이=칸 높이×0.35. 큰 무릎 접기 대신 도약 자세를 사용한다.
- 이동 판정·비용·출수/회수·피해·회복 등 기존 규칙과 수치는 유지했다. 본게임·저장·정식AI는 미통합이다.

## CLI 위치
- `mountain/main.gd`: 화면·시험 편성·산적 고정 행동·입력 잠금.
- `mountain/battle_board.gd`: 호흡·낮은 이동·배경·인물·범위 표시.
- `prototypes/timed_combat/combat_catalog.json`: 현재 행동·무공·장비 정의.
- 같은 폴더의 `combat_clock.gd`·`combat_rules.gd`: 시간축·판정. 그림이나 프레임 수로 피해를 재계산하지 않는다.
- `tests/jump_smoke.gd`, `mountain_smoke.gd`, `breathing_smoke.gd`: 전용 검사.

검토본 실제Godot4.6.3에서 낮은 이동71항목(상태/궤적46+이미지 저장25),기존 전투 연결45항목 통과. 이번 등록용 분리자료도 별도 대조 검사했다. ZIP은 변경 없는v5 스냅샷이며 다른 폴더의JSON수정을 자동 반영하지 않는다.

`전투/전투 캐릭터/`에는 인물별 대기 호흡·낮은 이동 설정과 공용 표시 함수가 있다. ZIP은 통합4×2이미지를 사용하고 Git의 인물별이미지는4×1이다. 픽셀을 그대로 행 분리했으며 공용함수는4×1에 맞췄다.
