# 큰 대바구니 1

![큰 대바구니 1](%ED%81%B0%20%EB%8C%80%EB%B0%94%EA%B5%AC%EB%8B%88%201.png)

범용 도시 실외 운반·수납 에셋. 정면1장(627×627 투명PNG)이며 뒷편은 제작하지 않았다. 사용자 등록 승인:2026-11-11.

[규격](규격.json)에 민가1 대비 크기·현재 기준 권장배율·근사 피벗을 기록했다. [충돌 초기안](충돌_초기안.json)은 수정 가능한 논리 타일 단위의 바닥 충돌이다. 원본 캔버스 크기를 실제 점유로 사용하지 않는다. 모든 소품에 같은 표시배율을 적용하지 않는다.

현재 민가1 공용 배율을 참조한 신규 소품 제안이며 기존 건물 규격은 변경하지 않았다. 실제 게임 배치·충돌·가림·길찾기는 미검증이며 원화 등록을 본게임 적용으로 간주하지 않는다.
