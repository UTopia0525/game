# 평범한 세면대 1

![평범한 세면대 1](%ED%8F%89%EB%B2%94%ED%95%9C%20%EC%84%B8%EB%A9%B4%EB%8C%80%201.png)

일반 가정용 사물. 기존 F 일러스트풍을 참고해 온전한 목재·천·도기로 제작했다.
기존 허름한 사물과 별도 자료이며 과한 낡음·수선 표현을 제외했다.

- `평범한 세면대 1.png`: 개별 투명 PNG. 사용자 검토본의 그림을 변경하지 않고 이름만 정리했다.
- `규격.json`: 기존 심리스 민가의 실내와 인물 축척을 참고한 수정 가능한 크기·충돌 초기값.
- 실제 게임 배치·통행·그림 시점 일치는 미검증이다. 접지 피벗과 실제 표시배율은 CLI 적용 시 정한다.
- 부속 찻잔·대야·옷·솥·선반 내용물 등은 이미지에 합쳐져 있다. 별도 개폐·상호작용·뒤 방향 그림은 없다.
