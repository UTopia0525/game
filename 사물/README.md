# 사물

건물과 별도로 분류하는 개별 배치용 그림이다.
기존 16종은 사용자가 일반 민가의 의도보다 지나치게 허름하다고 평가하여 **허름한 사물** 유형으로 보존·등록했다.
일반 민가용 가구의 기본 낡음 정도는 이 묶음을 기준으로 확정하지 않는다.

## 뒷편 원화와 좌우반전

각 에셋의 기존 폴더에 `기존이름_뒷편.png`를 추가했다. 원본 반대쪽 후면 사선1방향이며, 원래 정면 PNG는 변경하지 않았다.

- 정면과 뒷편의 원화 해상도·투명 여백이 다를 수 있다. 같은 물체의 논리 점유와 시각적 크기를 유지하고 뒷편용 접지 피벗·표시 배율을 따로 확인한다. 기존 규격의 점유·높이 제안값은 변경하지 않았다.
- 좌우반전은 그림뿐 아니라 부속 위치·정렬 기준·충돌·사용면·출입 좌표를 함께 변환하는 배치다. 비대칭 구조와 글자가 반전되어도 되는지는 실제 사용 시 확인한다. 별도의 반전 PNG는 만들지 않았다.
- 보이지 않던 후면 구조를 원화에서 추정해 새로 그린 자료다. 동일 건물/물체의 네 방향 전환·가림·실제 게임 배치는 미검증이며, CLI 연결 시 점검한다. 이번 등록에는 실행 코드·게임 통합·새 상호작용이 없다.
- 사물·가구32종의 뒷편32장을 등록했다. 옷장/수납장은 뒤판, 의자는 뒤쪽 등받이, 화덕은 화구가 없는 뒷벽, 옷걸이는 옷의 뒷면을 기준으로 했다.


## 수정 가능한 충돌 초기안 (2026-11-09)

각 사물32종의 기존 폴더에 `충돌_초기안.json`을 추가했다. 논리 타일 단위의 로컬 바닥 충돌과 접근/연결 여유를 기록한다. 접근공간은 물리 충돌이 아니다. 앞·뒷면은 같은 물체의 충돌을 공유한다.

원화는 변경하지 않았으며 값은 편집 가능한 제안이다. 기존 평범한 사물의 바닥 치수는 유지했다. 실제 원화 피벗·표시배율·논리 방향을 맞춘 뒤 사용해야 하며, 게임 충돌·길찾기·통행·접합 검증은 미실행이다. 다른 기존 문서의 미정 표시는 게임에 확정 적용되지 않았다는 뜻이며, 본 JSON은 적용 전 초기 제안이다.
