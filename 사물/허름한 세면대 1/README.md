# 허름한 세면대 1

![허름한 세면대 1](%ED%97%88%EB%A6%84%ED%95%9C%20%EC%84%B8%EB%A9%B4%EB%8C%80%201.png)

대야와 수건이 포함된 세면대. 기존 F 일러스트풍을 참고한 정면 PNG와 추가 뒷편 PNG를 보관한다.

- 분류: 허름한 사물. 낡음·수선 표현이 일반 민가의 목표보다 강해 별도 유형으로 등록했다.
- 원본 검토 파일: `10_세면대.png`. 그림을 수정하지 않고 이름과 분류만 정리했다.
- 표시 배율·점유 크기·접지 피벗·충돌·깊이 정렬은 미설정이다. 게임 적용 시 별도로 정한다.
- 이미지에 포함된 부속 물건은 한 PNG에 합쳐져 있다. 별도 조작·개폐 기능은 없다.

사용자 등록 승인: 2026-11-08. 기본 민가용 사물 전체의 낡음 기준을 확정한 것은 아니다.

- 원본 반대쪽 후면 사선1방향을 새로 제작했다. 기존 정면 파일은 변경하지 않았다.
- 원화 캔버스627×627px. 정면 원화의 픽셀 피벗·표시 배율을 그대로 복사하지 말고, 같은 논리 점유와 시각적 크기에 맞춰 CLI에서 확인한다.
- 가구의 뒤판·등받이·부속 물건 가림을 표현한 별도 원화다. 개폐·상호작용·배치 코드는 추가하지 않았다.
- 좌우반전 사용 시 부속 위치·충돌·사용면·출입 좌표를 같은 기준점에서 함께 변환하고, 글자/비대칭 구조와 실제 배치를 확인한다.
