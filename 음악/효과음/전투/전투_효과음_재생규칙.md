# 전투 효과음 재생 규칙

전투 효과음은 하나의 공용 재생 채널에서 한 번에 하나만 재생한다. 하급 무공에는 무기별 공용 공격음과 판정음을 쓴다. 재생 순서와 전환 시간은 화면 연출에만 적용한다. 전투 판정과 다음 행동 가능 시각은 전투 엔진이 정한다.

| 우선순위 | 소리 | 재생 기준 |
| --- | --- | --- |
| 1 | 명중·방어·밀치기 명중 | 같은 접촉에는 결과음을 하나 고른다. 일반 명중과 무거운 명중은 둘 중 하나를 쓴다. 방어가 피해를 일부 줄였으면 명중음을, 완전히 막았으면 방어음을 쓴다. 명중으로 상대가 실제 밀렸으면 밀치기 명중음을 쓴다. |
| 2 | 착지·발 끌림·쓰러짐 | 발이나 몸이 실제로 움직이는 화면 시점에 재생한다. 밀치기 명중음에 포함된 발 끌림은 한 번만 들린다. 피해를 받자마자 쓰러져 밀리는 동작이 생략되면 명중 후 몸이 닿는 시점에 쓰러짐을 표시한다. |
| 3 | 공격·발구름 | 휘두르거나 발을 뗄 때 재생한다. 빗나가면 공격음을 끝까지 재생한다. 공격음과 결과음이 같은 순간에 들어오면 결과음을 고른다. |
| 4 | 공격 예고·내기 모으기 | 행동이 확정되어 해당 동작을 시작할 때 한 번 재생한다. 채널이 사용 중이면 생략한다. 산적의 예고 유지 자세나 UI 갱신으로 다시 재생하지 않는다. |

더 높은 우선순위의 소리가 들어오면 현재 소리를 20~30ms 동안 줄여 종료한 뒤 새 소리를 재생한다. 같은 우선순위가 같은 순간에 몰리면 전투 사건 순서대로 첫 후보를 고른다. 같은 우선순위로 재생 중에 새 후보가 오면 현재 소리를 유지한다. 뒤늦게 들리는 소리를 막기 위해 밀린 후보를 대기열에 쌓지 않는다.

## 명중 후 밀치기

- 백운장이나 연환창법이 상대를 실제로 밀면 **짧은 충격 뒤 발 끌림이 이어지는 공용 밀치기 명중음 하나**를 재생한다. 충격과 발 끌림은 그 안에서 순서대로 들린다.
- 공격음이 이미 나오고 있으면 짧게 줄여 종료한 뒤 밀치기 명중음을 재생한다. 명중과 이동이 함께 보고되더라도 일반 명중이나 발 끌림을 따로 중복 재생하지 않는다.
- 밀치기 속성이 있는 기술도 대상이 실제로 밀리지 않았으면 일반 명중 또는 무거운 명중을 쓴다. 빗나가면 공격음만 쓴다.
- 밀치기 명중음은 재생 규격이며 현재 WAV 목록에는 아직 없다. 제작할 때는 공용 명중과 [밀치기 발끌림](04_추가/밀치기_발끌림.wav)을 참고해 한 클립으로 편집한다.

## 중복 방지와 확인

전투 사건으로만 재생 후보를 등록한다. 교전 ID, 행동 토큰, 타격 사건 ID로 같은 접촉을 묶는다. UI나 애니메이션도 사건을 읽을 수 있지만 오디오 재생은 공용 채널의 담당 코드에서만 처리한다. 재시작할 때는 재생 중인 이전 효과음과 중복 확인 기록을 정리한다.

산골 1대1에서 빗나감, 일반 명중, 완전 방어, 피해를 일부 줄이는 방어, 실제 밀치기 성공, 밀치기 실패를 비교한다. 빠르게 연달아 공격할 때 음이 겹치거나 한참 뒤에 나오지 않는지도 확인한다. 현재는 설계 문서다.
