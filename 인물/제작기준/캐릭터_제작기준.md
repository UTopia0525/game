# 캐릭터 제작기준

2026-11-08 사용자 확정. [도원 정지](../도원/정지/)와 [도원 보행](../도원/보행/) 원화를 앞으로 제작할 캐릭터의 공통 미술·애니메이션 표준으로 사용한다. 다른 인물의 얼굴·복식·체격·소품은 개별 설정에 따라 구별한다.

## 확정 원본

- 정지 8장: 정지 채색을 보행에 맞춘 최종 원화(v4).
- 보행 8장: 대각선 왼쪽 아래·왼쪽 위·오른쪽 위 수정(v5)과 마지막 위쪽 보행 수정을 모두 반영했다. 오른쪽 아래 보행은 사용자가 정상 기준으로 지정한 원본을 유지했다.
- 호흡 효과는 사용하지 않는다. 정지는 방향별 그림 한 장으로 고정한다.
- 이 저장소에는 확정 PNG와 이 공통 기준만 보관한다. 에셋목록 JSON·미리보기·중간 시안·시험 씬은 추가하지 않는다.

## 화풍·형태·채색

- 도원의 깔끔한 윤곽과 절제한 명암을 가진 F 일러스트풍을 따른다. 사진 같은 질감이나 다른 도트 화풍을 섞지 않는다.
- 약 4등신의 성인 체형과 도원 원화의 머리·어깨·몸통·팔다리 관계를 기준으로 한다. 등신 숫자나 캔버스 크기만 맞추어 통과시키지 않는다.
- 정지와 보행에서 같은 인물의 머리 크기·어깨 폭·몸통 길이와 두께·옷자락 체적을 유지한다. 자연스러운 무릎 굽힘·원근·작은 상하 움직임은 허용하되, 전환할 때 전체가 축소·확대되는 느낌은 없어야 한다.
- 도원의 피부·청회색 무복·상아색 소매와 깃·갈색 소품·흑갈색 머리는 확정 보행 원화의 채색과 명암을 기준으로 한다. 정지와 보행 사이에 색온도·채도·선명도가 튀지 않게 한다.
- 다른 인물에게 도원과 같은 옷 색을 강제하지 않는다. 인물별 색을 정한 뒤 모든 방향과 정지·보행에서 일관되게 유지한다.

## 파일·방향 규격

| 항목 | 기준 |
|---|---|
| 파일 형식 | 투명 배경 RGBA PNG |
| 단일 셀 | 384×512px |
| 정지 | 방향별 1장, 384×512px |
| 보행 | 방향별 8프레임, 1536×1024px |
| 보행 배열 | 4열×2행. 위 행 왼쪽부터 1~4, 아래 행 왼쪽부터 5~8 |
| 발밑 기준점 | 각 셀의 (192, 500) |
| 파일명 | 아래 표의 한글 방향명을 사용 |

방향은 **화면 기준**이다. 몸에 착용한 무기의 좌우는 인물 자신의 몸 기준으로 구분한다.

| 방향 | 파일명 |
|---|---|
| S | 아래.png |
| SW | 왼쪽아래.png |
| W | 왼쪽.png |
| NW | 왼쪽위.png |
| N | 위.png |
| NE | 오른쪽위.png |
| E | 오른쪽.png |
| SE | 오른쪽아래.png |

각 인물은 `인물/인물이름/정지/`, `인물/인물이름/보행/`에 같은 방향명으로 저장한다. 확정 원화를 다시 자르거나 방향·프레임마다 확대·축소해 맞추지 않는다.

## 보행·소품

- 도원의 확정 오른쪽 아래 보행을 보폭·팔 흔들림·안정된 몸통의 기준으로 삼고, 다른 시점의 원근과 가림을 반영한다.
- 좌우 지지 다리가 교대하고 팔은 같은 쪽 다리와 반대 박자로 움직이게 한다. 발목 교차·과도한 무릎 들기·팔이 계속 앞으로 굽어 고정되는 자세·부자연스러운 반복을 피한다.
- 8프레임이 처음으로 돌아갈 때 동작이 자연스럽게 이어져야 한다. 정지·보행·방향 전환에서도 크기와 접지 기준이 튀지 않게 한다.
- 도원의 검과 검집은 **도원 자신의 왼쪽 허리**에 고정한다. 시점에 따른 가림은 허용하지만 좌우 반전으로 착용 위치가 바뀌지 않게 한다. 다른 인물의 소품도 해당 인물의 설정을 일관되게 따른다.

## 게임 연결 시 참고

확인에 사용한 기존 시범의 표시 배율은 0.1875, 이동 속도는 논리 타일 기준 4.8/초, 발밑 충돌 반경은 0.15, 카메라 배율은 0.85다. 셀 높이 512×표시 배율=96은 캔버스 환산 높이이며 실제 그려진 인물의 전신 높이와 다르다.

이 값들은 기존 시범의 연결 참고값이다. 새 그림을 맞추려고 인물 크기·이동 속도·카메라를 임의로 바꾸지 않는다. 통합 프로젝트의 경로·애니메이션 등록·게임 동작은 CLI에서 현재 구조에 맞춰 연결한다. 이 자료 등록은 통합 프로젝트 작동 검증을 뜻하지 않는다.

## 후속 캐릭터 확인 순서

1. 도원 옆에 같은 배율과 발밑 기준으로 표시해 화풍·체형·선명도를 비교한다.
2. 해당 인물의 8방향 정지·보행에서 크기·체적·채색·소품 위치를 비교한다.
3. 실제 표시 배율에서 이동 시작·정지·방향 전환·보행 반복을 확인한다.
4. 사용자 검토 후 확정본만 저장한다. 그림의 해상도나 자동 검사 통과만으로 미술 완성을 판정하지 않는다.
