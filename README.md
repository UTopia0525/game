# 무협 게임 확정 자료

사용자가 등록을 승인한 자료를 알아보기 쉽게 분류한다.
업로드 전 대상 파일과 폴더를 안내하고 사용자 확인을 받는다.
그림 등록 승인과 규격·본게임 적용 확정 여부는 각 자료에서 구분한다.

## 현재 자료

- [건물](건물/README.md): 건물23종의 앞·뒷면46장. 민가5종·실용 건물5종·상업문화5종·객잔3종·관아/무관 본채2종·사당/노점3종을 새 공통 기준으로 교체·등록했다. [00_제작기준](건물/00_제작기준.md)에 직육면체 전체 축 정렬 원칙을 기록했으며, 새 원화의 점유·피벗·배율·충돌은 실제 적용 시 등록한다.
- [사물](사물/README.md): 허름한16종·평범한16종의 앞뒤64장과 범용 도시 실외20종의 정면20장, 총52종84장. 종류별 크기·충돌 초기안을 포함하며 실외20종은 뒷편이 없다.
- [인물 제작기준](인물/00_제작기준/캐릭터_제작기준.md) · [도원](인물/도원/): 확정 정지 8장·보행 8장. 마지막 위쪽 보행 수정까지 반영했으며 호흡 효과는 사용하지 않는다.
- [타일](타일/README.md): 기본 바닥·자연 강변·석축 수로·논둑과 다리 원화64장. 재질·물 방향·연결 형태를 한글 이름으로 구분한다. 이미지 보관을 승인받은 자료이며 반복 배치·경계·알파 정리와 게임 적용은 별도 확인 대상이다.

- [울타리](울타리/README.md): 나무울타리·기와 회벽담의 A/B축 직선, 기둥, 모서리와 문 없는 출입구 앞·뒷면12장 및 기존 도시 성곽·열린 성문2장. 도시 성곽 연결 기둥 원본은 미확보이며 접합·충돌·통행 규격은 적용 시 확인한다.

무기·무공·퀘스트·스토리 분류는 해당 자료를 승인받아 등록할 때 만든다.
개발 중간 자료·검사 로그·전체 프로젝트 백업은 이 저장소에 일괄 업로드하지 않는다.

건물23종·사물52종·울타리/담장/성곽10종의 수정 가능한 충돌 초기안을 각 자료 폴더에 등록했다. 실제 프로젝트에 적용·검증된 충돌값과 구분한다.
