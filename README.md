# 무협 게임 확정 자료

사용자가 등록을 승인한 자료를 알아보기 쉽게 분류한다.
업로드 전 대상 파일과 폴더를 안내하고 사용자 확인을 받는다.
그림 등록 승인과 규격·본게임 적용 확정 여부는 각 자료에서 구분한다.

## 현재 자료

- [건물](건물/README.md): 기존 민가 1·2와 도시 건물 12종 및 각 건물의 뒷편 원화. 이름으로 외관 성격·층수·용도를 구분하며 수정 가능한 크기 초안을 포함한다.
- [사물](사물/README.md): 허름한 사물 16종과 평범한 사물 16종 및 사물32종 각각의 뒷편 원화. 평범한 사물에는 수정 가능한 배치·충돌 초기 규격을 포함한다.
- [인물 제작기준](인물/00_제작기준/캐릭터_제작기준.md) · [도원](인물/도원/): 확정 정지 8장·보행 8장. 마지막 위쪽 보행 수정까지 반영했으며 호흡 효과는 사용하지 않는다.
- [타일](타일/README.md): 기본 바닥·자연 강변·석축 수로·논둑과 다리 원화64장. 재질·물 방향·연결 형태를 한글 이름으로 구분한다. 이미지 보관을 승인받은 자료이며 반복 배치·경계·알파 정리와 게임 적용은 별도 확인 대상이다.

- [울타리](울타리/README.md): 나무울타리·기와 회벽담의 기둥 없는 직선, 기둥, 90도 모서리와 기존 열린 대문 앞·뒷면 총 10장. 접합·충돌·통행 규격은 적용 시 확인한다.

무기·무공·퀘스트·스토리 분류는 해당 자료를 승인받아 등록할 때 만든다.
개발 중간 자료·검사 로그·전체 프로젝트 백업은 이 저장소에 일괄 업로드하지 않는다.
