- 각각887×887 투명RGBA PNG다. 캔버스 크기는 논리 점유 크기가 아니다.
- [공통 건물 제작 기준](../00_제작기준.md)을 따른다. 지붕뿐 아니라 벽·기단·바닥을 같은 직육면체에서 구성해 같은 방향의 구조선을 평행하게 유지한다. 긴 축 약-21도·짧은 축 약+23도는 제작 목표다.
- 앞뒤 몸체·층고·지붕을 같은 기준도로 제작했고 새 후문은 추가하지 않았다. 돌출된 방·부속채·발코니는 없다.
- `규격.json`의 점유·접지 피벗·배율·물리충돌·출입 영역은 재등록 전이라 미확정이다. 과거 원화의 값을 자동으로 재사용하지 않는다.
- 좌우반전 시 정문·피벗·충돌·정렬 좌표도 함께 변환한다.21/23도는 비대칭이므로 반전 후 고정 도로 축과의 차이는 실제 배치에서 확인한다.
- 열린 공간·그림 속 작업대/급이대는 외관에 통합된 그림이다. 실행 가능한 실내·출입·개폐·작업 기능을 구현한 것은 아니다.

RGBA·크기·주요 실루엣 잘림·해시 일치를 확인했다. 육안·대표 장축 검토와 사용자 원화 승인은 전체 선의 수학적 일치·필드 통행·가림·깊이 정렬 검증과 구분한다. 실제 게임에는 적용하지 않았다.
