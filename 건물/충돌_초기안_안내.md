# 건물 23종 충돌 초기안

기존20종과 사당·노점2종 총23종. 사용자 승인으로 저장소에 등록한 수정 가능한 초기안이다. 본게임은 변경하지 않았다.

각 건물 폴더의 충돌_초기안.json을 기존 규격과 별도로 작성했다. 값은 편집 가능한 논리 타일 단위의 제안이며 그림의 실측치·최종 규격이 아니다. 피벗·표시배율은 실제 프로젝트에서 원화 바닥과 논리 footprint를 맞춘 뒤 결정한다. 기존 인물 발밑 반경0.15는 과거 시범 참고값이며 통합 프로젝트 값은 미확인이다.

일반 건물은 출입 미연결 상태용 전체점유 차단과 향후 심리스용 벽/문틈을 별도 모드로 제시한다. 동시에 적용하면 문이 막힌다. 현재 열린 출입구 그림만으로 실내에 들어갈 수 있게 되지는 않는다. 마구간 복수 개방부는 별도 정합이 필요해 심리스용 후보 적용을 보류했다. 노점은 기둥·판매대만 충돌하며 차양과 판매자 통로를 차단하지 않는다.

확인 범위: 수치·양수 크기·외벽 범위·기본 문 여유의 정적 계산. 실제 게임 충돌·길찾기·NPC 교행·반전/후면 정렬·카메라에서의 축척 검증은 실행하지 않았다.

각 건물의 규격.json에서 충돌_초기안.json을 참조한다. 규격의 기존 물리충돌=null은 실제 게임에 확정 적용되지 않았다는 뜻이며, 초기 제안 수치가 없다는 뜻이 아니다.
