두 그림은 사용자 승인으로 등록했다. 2026-11-09 앞·뒷면을 사용자 승인 최신 원화로 교체했다. 규격의 논리 점유는 과거 시범의 참고값이며 새 원화의 픽셀 피벗·배율·문 좌표는 재등록 전이다.
같은 화풍과 인물 축척을 유지하되 도시·생활 수준·용도에 따른 건물 차이를 허용한다.
동일 그림이나 조립 부품의 반복 사용을 필수로 하지 않는다.

각 민가 폴더의 정면·`_뒷편.png`를 함께 교체했다. 후문은 추가하지 않았다. 공통 시점과 직육면체 축 정렬은 [건물 제작 기준](../00_제작기준.md)을 따른다.
