- 외관 성격: 단정함·섬세한 격자. 용도: 서점. 외관상 2층.
- 각 원화는 887×887 투명 PNG다. 깔끔한 F 일러스트풍을 유지한다.
- [공통 제작 기준](../00_제작기준.md)의 긴 축 -21도·짧은 축 +23도 가이드를 참고해 본체·지붕·기단을 함께 정렬했다. 모든 선의 수학적 일치나 실제 필드 배치 검증을 뜻하지 않는다.
- 돌출된 방·부속채를 제거했다. 후문은 추가하지 않았다.
- 지역 미술 참고: 남경. 배치 가능한 도시를 제한하지 않는다.

[규격.json](규격.json)의 과거 점유 제안은 초기화했다. 도원 축척과 도로에 맞춰 논리 점유·접지 피벗·표시 배율·문 영역·충돌을 다시 등록해야 한다. 좌우반전 시 기준 축과 문·충돌 좌표도 함께 검토한다.

실내·지붕 및 벽 분리·층 이동·심리스 기능·게임 통합은 포함하지 않는다. 본게임·저장·퀘스트·경제·시험 씬은 수정하지 않았다.
