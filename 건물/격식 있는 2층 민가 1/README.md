- 앞뒤의 몸체 규모·기단·층 높이·지붕 중심을 함께 검토하고, 후문은 추가하지 않는다.
- 좌우반전 시 그림뿐 아니라 정문·피벗·충돌·정렬 좌표도 같이 바꾼다.21/23도는 비대칭이므로 고정 도로 축과의 차이는 실제 배치에서 확인한다.
- `규격.json`의 이전 원화 픽셀 피벗·배율·문 좌표는 무효 처리했다. 새 원화에 맞는 방향별 기준점을 다시 등록해야 한다.
- 원화 등록 승인과 실제 필드의 충돌·통행·가림·깊이 정렬 검증은 별개다. 모든 구조선이 수학적으로 정확히 목표와 일치한다고 검증한 것은 아니다.
