# 건물

이름에 외관의 성격·주동 층수·용도를 넣어 배치 자료를 고르기 쉽게 정리한다.
층수 표기가 없는 이번 신규 건물은 단층이다. 격식·화려함은 외관을 설명하는 참고 구분이다.
기존 자료 [민가 1·2](민가/README.md)는 원래 폴더를 유지한다.

[공통 건물 제작 기준](00_제작기준.md): 건물 전체를 하나의 직육면체로 구성해 지붕·벽·기단·바닥의 같은 축을 평행하게 유지한다.

2026-11-09 민가5종(민가1·민가2·수수한 민가1·화사한 민가1·격식 있는2층 민가1)의 앞뒤10장을 사용자 승인 최신 원화로 교체했다. 파일명·폴더는 유지했고 이전판 PNG는 현재 자료에 별도 보관하지 않는다.

2026-11-09 실용 건물5종도 반영했다. 공방은 앞뒤2장을 교체했고, 창고1·2/헛간/마구간4종은 앞뒤8장을 새 폴더에 등록했다. 현재20종40장 모두 새 공통 제작 기준으로 교체·등록된 자료다.

2026-11-09 점포·비단점·찻집·서점·회관5종의 앞뒤10장을 사용자 승인 최신 원화로 교체했다. 점포·비단점 중앙 출입구 수정도 포함한다.

2026-11-09 객잔3종의 앞뒤6장을 교체하고 관아·무관 본채2종의 앞뒤4장을 새 폴더에 등록했다. 물리 충돌·피벗·배율·문 영역은 실제 게임 적용 전 별도 등록 대상이다.

## 뒷편 원화와 좌우반전

각 에셋의 기존 폴더에 `기존이름_뒷편.png`를 추가했다. 후면 사선 원화다. 민가5종·공방은2026-11-09 앞·뒷면을 교체했고 실용 시설4종은 새로 등록했다. 상업문화5종도 앞뒤 교체했고 객잔3종도 교체했고 관아·무관 본채2종을 신규 등록했다.

- 정면과 뒷편의 원화 해상도·투명 여백이 다를 수 있다. 같은 물체의 논리 점유와 시각적 크기를 유지하고 뒷편용 접지 피벗·표시 배율을 따로 확인한다. 현재 새 기준의 건물20종은 원화에 맞는 픽셀 피벗·배율·점유·충돌을 다시 등록해야 한다. 과거 부속채 포함 점유 제안은 자동 재사용하지 않는다.
- 좌우반전은 그림뿐 아니라 부속 위치·정렬 기준·충돌·사용면·출입 좌표를 함께 변환하는 배치다. 비대칭 구조와 글자가 반전되어도 되는지는 실제 사용 시 확인한다. 별도의 반전 PNG는 만들지 않았다.
- 보이지 않던 후면 구조를 원화에서 추정해 새로 그린 자료다. 동일 건물/물체의 네 방향 전환·가림·실제 게임 배치는 미검증이며, CLI 연결 시 점검한다. 이번 등록에는 실행 코드·게임 통합·새 상호작용이 없다.
- 현재 건물20종에 앞면20장·뒷편20장을 보관한다. 사용자 결정에 따라 후문은 추가하지 않았다. 정문이 카메라 반대편에 있어 가려지는 것은 정상이며, 실제 정문으로 도로·접근로를 연결한다.
