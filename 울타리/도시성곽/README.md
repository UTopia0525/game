# 도시 성곽

사용자가 보관을 승인한 도시 성곽 원화다. 기존 울타리보다 높고 두꺼운 회색 석조 구조이며, 성인 약 3명 높이는 제작 목표일 뿐 게임에서 확정한 표시 규격은 아니다.

- `도시성곽_직선성벽.png`: 마지막 수정 합본의 위쪽 직선 성벽을 분리했다. 별도 큰 끝 기둥이 없는 본체이며 반대 사선 축은 좌우반전해 사용한다.
- `도시성곽_성문_열림.png`: 마지막 수정 합본의 아래쪽 열린 성문을 분리했다. 옆의 긴 성벽 날개를 제거한 형태다.

## 출처와 분리

원본 합본 `exec-a73a441f-03f6-4c45-9349-932f336ec403.png`에서 재채색·리사이즈 없이 부품별 영역을 분리하고 투명 여백을 추가했다. 성벽 아래의 인접 성문 조각이 포함되지 않도록 분리 영역 일부를 비웠다. 원본의 반투명 배경 효과는 그대로 남아 있으며 완전히 정리된 게임용 알파로 보증하지 않는다.

앞서 제시한 별도의 사각 연결 기둥은 현재 작업 공간에 원본 파일이 남아 있지 않아 등록하지 않았다. 임의의 새 그림으로 대체하지 않았다.

## 배치 시 확인할 사항

- 도시 전체를 감싸는 직선 반복과 모서리 접합, 성가퀴 간격·양 끝 단면은 아직 게임에서 검증하지 않았다. 기둥·모서리 원화 복구 및 실제 접합 검토가 필요하다.
- 2D 이미지의 화면상 90도 회전은 수직 구조까지 기울인다. 반대 사선 축에는 수평 반전과 연결점·피벗·충돌 좌표의 동반 변환을 사용한다.
- 성문은 앞뒤를 동일한 구조로 설계하려는 목표다. 현재는 한 시점만 존재하며 뒤에서 보이는 두께·열린 문짝·아치 내부까지 같은 이미지로 표현할 수 있다고 검증하지 않았다.
- 문 통로를 비우고 양쪽 지지부와 문짝의 충돌, 아치 상부의 가림·깊이 정렬을 구분한다. 기존 낮은 울타리 대문의 폭 1.5칸 제안을 도시 성문의 확정 폭으로 자동 적용하지 않는다.
- 최종 표시 크기·연결 좌표·충돌·알파 정리·게임 통행은 미확인이다. 미술 보관만 진행했으며 게임 코드와 씬은 변경하지 않았다.
