# 울타리와 담벼락

등록을 승인받은 개별 PNG 12장이다. 미술 등록과 게임 배치·충돌 규격 확정은 구분한다.

- [나무울타리](나무울타리/): 낮은 목제 울타리와 지붕 없는 열린 대문.
- [기와회벽담](기와회벽담/): 밝은 회벽·석재 기단·회색 기와 덮개와 열린 기와 대문.

- [도시성곽](도시성곽/): 높은 직선 성벽·열린 성문 2장. 별도 연결 기둥 원본은 미확보 상태이며 접합·게임 적용은 미검증이다.

## 나무울타리·기와회벽담 파일 구성

각 폴더에 다음 5개 PNG를 둔다. 파일 이름 앞에는 종류 이름이 붙는다.

| 이름 끝부분 | 용도 |
|---|---|
| 직선본체_기둥없음 | 새로 수정한 기둥 없는 직선. 반대 사선 방향은 좌우반전으로 사용 |
| 기둥 | 기존 공용 기둥. 연결·끝마감·모서리에 하나씩 사용 |
| 90도모서리 | 기존의 기둥 포함 일체형 모서리. 그려진 방향에 사용 |
| 대문_열림 | 기존 열린 대문 앞면 |
| 대문_열림_뒷편 | 기존 열린 대문 뒷면 |

닫힌 문과 양 끝 큰 기둥이 포함된 이전 직선은 등록하지 않았다. 대문 그림은 이번 수정에서 변경하지 않았다.

## 배치 원칙

- 직선 본체는 한 방향 원화만 보관하며 반대 축은 수평 반전한다. 수직 기둥이 기울어지는 화면상 90도 회전이나 상하 반전을 하지 않는다. 반전 시 피벗·연결점·충돌 좌표도 함께 변환한다.
- 직선 끝 사이에 공용 기둥 하나를 두고, 본체 끝이 기둥 옆면에 닿도록 맞춘다. 그림의 투명 여백이나 캔버스 폭을 반복 간격으로 쓰지 않는다.
- 다른 모서리 방향은 두 방향의 직선과 공용 기둥 하나로 조합할 수 있다. 기존 일체형 모서리에는 이미 기둥이 있으므로 공용 기둥을 중복 배치하지 않는다. 일체형은 담장 두 팔을 따로 깊이 정렬할 수 없다는 제약이 있다.
- 대문은 자체 문기둥을 사용하므로 그 자리에 공용 기둥을 추가하지 않는다. 대문의 반대 사선 축도 좌우반전할 수 있다.
- 본체·기둥·대문의 원화 캔버스 크기는 서로 다르며 실제 게임 점유 크기가 아니다. 같은 수치의 배율을 무조건 적용하지 말고 접지 기준·표시 높이·접합점을 맞춘다.

## 수정 가능한 통행 규격 제안

1칸은 기존 아이소메트릭 논리 타일 1개다. 대문 유효 통행 폭은 1.5칸 이상, 앞·뒤 여유 깊이는 각각 1칸 이상을 제안한다. 문기둥 폭은 각각 약 0.25칸, 기둥 포함 정면 폭은 약 2칸을 시작안으로 삼는다. 기존 도원의 발밑 충돌 반경은 0.15칸이다.

위 값은 원화에 실측 적용되거나 게임에서 검증된 값이 아니다. 기존 대문은 유지했으며 CLI 적용 시 열린 문짝까지 포함해 통로 침범 여부를 확인해야 한다. 문기둥·담장·열린 문짝에는 필요한 충돌을 두되 중앙 통로는 비워 두고, 기와지붕의 시각적 가림은 통로 충돌과 분리한다.

## 확인 범위

파일 복사 후 원본과 바이트 일치·PNG 크기·RGBA 형식을 확인했다. 접합 피벗·반복 이음·최종 표시 크기·충돌·깊이 정렬·게임 통행은 아직 확인하지 않았다. 게임 코드와 기존 미술은 변경하지 않았다.
