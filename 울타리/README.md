# 울타리·담장·성곽

사용자 승인 원화와 수정 가능한 충돌 초기안이다. 원화 등록과 실제 게임 정합·통행 검증은 구분한다.

- [나무울타리](나무울타리/): 낮은 목제 울타리와 문짝 없는 기둥형 출입구6장.
- [기와회벽담](기와회벽담/): 회벽·석재 기단·기와 덮개와 문짝 없는 기와 출입구6장.
- [도시성곽](도시성곽/): 기존 직선 성벽·열린 성문2장. 이번 축선 수정 범위에는 포함하지 않았다.

## 원화 구성

각 울타리·담장 폴더에는 종류 이름을 접두어로 한 다음6개PNG가 있다.

| 이름 끝부분 | 내용 |
|---|---|
| 직선본체_기둥없음 | 기존 B축 약+23도 원화 유지 |
| 직선본체_A축_기둥없음 | A축 약-21도 신규 원화 |
| 기둥 | 독립 공용 기둥 수정 |
| 90도모서리 | 중앙 기둥1개·팔 끝 기둥 없는 모서리 수정 |
| 출입구_문없음 | 문짝 없는 고정 출입구 앞면 |
| 출입구_문없음_뒷편 | 같은 고정 출입구 뒷면 |

문짝·경첩·손잡이·개폐 동작은 없다. 나무 출입구는 기둥2개만, 담장 출입구는 기둥·윗보·기와지붕을 유지한다. 과거 대문_열림/대문_열림_뒷편 파일은 현재 폴더에서 제거했다. 기존 경로를 참조하는 프로젝트는 출입구_문없음 경로로 갱신해야 한다. 본게임 코드는 변경하지 않았다.

## 방향과 접합

[건물 공통 기준](../건물/00_제작기준.md)의 두 지면축 -21/+23도를 참고했다. +23도 원화를 좌우반전하면 -23도가 되므로 정확한 양축 정렬을 보장하지 않는다. 직선은 방향별 A/B 원화를 사용하고 논리 충돌·접합점·피벗에도 같은 방향 변환을 적용한다. 화면90도 회전·비균등 확대는 하지 않는다.

직선 본체 끝에는 공용 기둥 하나를 공유한다. 중앙 기둥 포함 모서리나 자체 지지부를 가진 출입구에 별도 기둥을 중복 배치하지 않는다. 모서리의 현재 로컬 팔 방향은 u+,v-다. 과거 u+,v+ 충돌안과 혼용하지 않는다.

## 충돌 초기안

종류별 충돌_초기안.json은 논리 타일 단위의 수정 가능한 제안이다. 출입구는 기둥2개만 충돌하며 중앙 통로1.5칸을 비운다. 문짝 충돌은 제거했다. 지붕·윗보는 발밑 충돌이 아니다. 접근여유는 장애물이 아니다. 앞뒤 원화는 같은 물체의 충돌을 공유한다.

시각 원화의 픽셀 피벗·표시배율·사용 방향과 맞추기 전에는 자동 적용하지 않는다. 성곽의 통행 규격은 해당 기존 초기안을 참조한다.

## 확인 범위와 남은 검토

원화 형식·파일 해시·통로를 막지 않는 충돌 사각형·간이 접합을 확인했다. 직선3개+공유기둥4개는 실제 원화의 균등 축소·근사 접지점을 이용해 육안 비교했다. 실제 게임·픽셀 이음·길찾기·출입·후면 및 출입구 반대축 정렬은 미검증이다.

대표선 근사상 새 나무 모서리 발밑은 약-22.6/+23.7도, 담장 모서리는 약-20.9/+21.7도다. 목표 -21/+23도와 일부 약1~2도 차이가 남는다. 모든 선이 수학적으로 일치한다고 판정하지 않았다. 도시성곽 각도·접합과 별도 연결 기둥 원본은 추가 검토 대상이다.
