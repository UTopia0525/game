# 도원 도·창 전투 자세

현행 검 도원과 같은 화면 오른쪽을 향한 전투 시점으로, 두 무기별 대기·공격·방어·피격 원화를 만들었다. 복식과 체형, 발밑선을 같은 배율에서 대조했다.

- 도는 기존 필드 도원의 도집과 이전의 후배도 설명을 참고했다. 두꺼운 칼등과 한쪽 날을 주고 끝만 완만하게 휘도록 했다. 오른손에 도를 들고 도집은 인물의 왼쪽 허리에 뒀다.
- 창은 이전 균형창의 데이터 설명과 창을 쥔 전투 자세를 참고했다. 현재 필드 원화의 은회색 잎형 창날, 갈색 창대, 짧은 적갈색 매듭을 이어 썼다. 양손으로 창대를 잡는 위치와 찌를 때 뒷발에서 앞발로 체중이 옮겨가는 자세를 구분했다.
- 이전 저장소의 참고 위치는 `UTopia0525/-` 체크아웃 `56094c5`의 `godot/data/weapons.json`, `godot/assets/battle/hero-poses.png`이다. 현행 몸체 기준은 `UTopia0525/game` `dea4af5`의 `전투/전투 캐릭터/도원/전투자세.png`와 `인물/도원`의 무기별 정지 원화다.

각 시트는 투명 RGBA 3584×512px이며 896×512px 셀 4개를 가로로 배열했다. 왼쪽부터 대기, 공격, 방어, 피격이다. 발밑 등록점 후보는 (384,500)이다. 창을 내민 자세에서 끝까지 표시할 수 있게 가로 여백을 늘렸다. Godot 연결 시 기존 검 시트의 384px 셀을 읽는 설정 대신 이 시트의 셀 너비와 등록점을 지정해야 한다.

PNG 규격, 발밑 가로 기준선, 프레임 배열과 가장자리 잘림을 확인했다. 자세 원화에는 전용 무공의 재생 프레임과 효과는 포함되지 않는다. 게임에서의 렌더링과 판정 연결은 확인 전이다.
