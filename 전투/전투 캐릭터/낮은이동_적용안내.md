# 낮고 빠른 기본 이동 — v5

각 인물의 `점프자세.png`와 `낮은이동.json`, 공용 `낮은이동.gd`를 함께 사용한다. 원화는4×1 시트(384×512 셀)이며 준비·도약·공중·착지 순서다. 현재 낮은 이동에는 과한 무릎 접기를 피하려고 공중칸 대신 도약칸을 사용한다. 기존 `전투자세.png`·대기 호흡 자료는 유지했다.

준비0.06초+공중0.30초+착지0.10초=0.46초, 궤적 높이=칸 높이×0.35. 기존0.82초·×1.15보다 낮고 빠른 표시다. 수치는 게임 출수/회수T가 아니다.

## CLI 연결
1. 실제 엔진의 기본 `move` 이동 사건을 받은 뒤 이전/새 논리 칸을 화면의 발밑 좌표로 바꾼다. 이 표시 코드가 논리 위치를 다시 변경하면 안 된다.
2. 표시용 실제 경과 초와 칸 높이를 `sample(profile, start_foot, end_foot, cell_height, elapsed_seconds, head_room)`에 전달한다. `head_room`에는 상단에서 인물이 잘리지 않을 실제 여유를 전달한다.
3. 반환값의 `ground` 위치에 그림자, `ground-Vector2(0,lift)`에 `draw_pose()`로 인물을 표시한다. 인물 배율은 그대로다. 그림자는 공중일 때 조금 작고 옅게 하는 것을 추천한다.
4. `finished`가 참이면 이동 표시를 끝내고 기존 대기 그림·호흡으로 복귀한다. 결과pose=-1은 대기 복귀 신호이며 점프 시트에서 읽는 칸이 아니다.
5. 수동 사건 진행 화면은 이동 연출 중 다음 사건/추가 행동을 막는다. 취소·재시작·종료·피격·강제이동에는 표시만 정리하고 엔진의 실제 위치·피해·행동 상태를 따른다.

밀치기·돌진·후퇴를 자동으로 이 점프로 바꾸지 않는다. 선택 미리보기만으로 연출을 시작하거나 자원을 쓰지 않는다. 논리 이동의 시간·비용·회피·무적 규칙을 바꾸지 않는다.

PNG에는 몸과 무기가 함께 그려져 있다. 무기 길이 등 원화 세부 정합은 보류인 시안이며 기존 전투 원화를 대체한 것은 아니다. 방향별 점프 원화도 완비되지 않았다. 무공별·무기 교체 체계는 인계용 폴더의 별도 **설계안**을 참고하며 구현 완료로 취급하지 않는다.
