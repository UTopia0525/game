# 산적 공용 공격 예고

두 번째 시안의 낮은 자세를 산적의 공용 공격 예고로 사용한다. 산적이 무릎을 굽히고 도를 허리 뒤로 당긴다.

[투명 PNG](공격예고.png)는 1280×576px이며, 왼쪽부터 예고 시작과 유지 자세다. 셀은 640×576px, 발밑 등록점은 (320, 544)이다. [프레임 정보](공격예고.json)를 참고한다.

공격이 확정되어 출수 단계에 들어가면 시작 자세를 한 번 표시하고, 실제 발동 또는 취소까지 유지 자세를 보여준다. 기술명과 범위는 기존 전투 예고 데이터에서 읽는다. 게임 연결은 확인 전이다.
