# 전투 캐릭터 대기 호흡

기존 `전투자세.png`는 변경하지 않았다. PNG만 교체하면 움직이는 방식이 아니라 각 인물의 `대기호흡.json`과 공용 `대기호흡.gd`를 연결해 쓰는 표시 효과다. 현재4×1 시트(대기·공격·방어·피격 순서)에 맞춘 코드다.

| 인물 | 주기 | 위상 | 진폭 |
|---|---:|---:|---:|
| 도원 |1.6초|0|원본6px|
| 산적 |1.85초|0.37주기|원본6px|

진폭은 원본 이미지 좌표 기준이며, 검토 화면에서는 약2~3화면px다. 얼굴·상체·손·무기 영역(y420까지)은 같은 양만큼 이동한다. 하체에서 부드럽게 보정하고 발바닥(y485~)과 기준점(192,500)은 고정한다. 가로 변형이나 전체 확대·축소는 없다.

## CLI 연결
1. 캐릭터 폴더와 공용GDScript를 대상 Godot 프로젝트로 복사한다.
2. 공용 스크립트를 preload하고 `read_profile()`로 해당 캐릭터JSON을 읽는다. PNG 경로는JSON과 같은 폴더의 `전투자세.png`다.
3. 표시용 시간은 `_process(delta)`에서만 누적한다. 논리 전투T를 넘기거나 호흡 때문에 엔진을 진행하지 않는다.
4. 대기 자세의 `_draw()` 안에서만 아래를 호출한다. 인물의 발밑 위치·기존 표시 배율을 그대로 전달한다.

```gdscript
# 아래 변수들은 호출하는 캐릭터 표시 코드에서 준비한다.
Breathing.draw_idle(self, texture, foot_position, display_scale,
    render_seconds, profile, blend)
```

`blend`는0~1이며 대기 복귀 시 `blend_seconds`(0.18초)에 걸쳐1로 올린다. 공격·방어·피격·전투불능·교전 종료에는 이 함수를 호출하지 말고 기존 해당 자세를 표시한다. 대기 선택 중 논리 시간이 멈춰도 표시용 시간은 계속 흐르게 한다.

JSON의기간·위상·진폭은 확인한 v3 검토본에서 추출했다. 공용 함수는 GitHub에 저장한 인물별4×1 PNG를 직접 사용하도록 UV만 맞췄으며 같은 변위 규칙을 쓴다. 본게임·전투 수치·AI·기존 실행ZIP은 이 등록만으로 바뀌지 않는다. 동작 확인 후 프로젝트에 연결한다.
