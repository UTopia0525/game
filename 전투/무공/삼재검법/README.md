# 삼재검법

- [애니메이션 시트](삼재검법_연결_시트.png)는 화면 오른쪽을 보는 도원의 투명 PNG다. 512×512px 셀을 4열×3행으로 배치했다. 왼쪽 위부터 차례로 12프레임을 읽는다. 발밑 등록점 후보는 (256, 500)이다.
- [프레임 정보](프레임_정보.json)에 자세 순서와 검토용 재생 시간을 기록했다. 게임 재생과 등록점은 검증 전이다. 7→8번의 뒷발과 11→12번의 복귀 자세는 적용할 때 확인할 부분이다.
- [아이콘](아이콘.png)은 이전 저장소의 [아이콘 매핑](https://github.com/UTopia0525/-/blob/1cbffa22cb89ced817b0b4dde661d9298005e956/godot/data/icon_manifest.json)이 가리키는 [공용 시트](https://github.com/UTopia0525/-/blob/1cbffa22cb89ced817b0b4dde661d9298005e956/godot/assets/icons/martial.png)의 첫째 줄 셋째 칸이다. 게임의 소수점 경계 (627, 0, 940.5, 313.5)를 포함하는 정수 픽셀 범위로 추출했다. 크기는 314×314px다.
- 무공 데이터는 [기존 삼재검법 JSON](../삼재검법.json)에 있다.
