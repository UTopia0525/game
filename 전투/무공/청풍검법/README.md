# 청풍검법

도원이 화면 오른쪽을 바라보며 한 칸 전진한 뒤 가로로 베는 애니메이션이다.

- [투명 PNG 시트](청풍검법_시트.png)는 640×512px 셀을 4열×2행으로 배치했다. 왼쪽 위부터 행 순서로 8프레임을 읽는다. 발밑 등록점 후보는 (256, 500)이다.
- [재생 GIF](청풍검법_동작.gif)는 내려받아 브라우저에서 바로 확인할 수 있다. 지면의 두 점은 검토용 한 칸을 표시한다.
- [프레임 정보](청풍검법_프레임정보.json)에 검토용 시간과 이동 오프셋이 있다. 게임 연결 시에는 [기존 무공 데이터](../청풍검법.json)와 엔진 판정으로 실제 이동·발동을 처리한다.
- Godot 재생은 검증 전이다. 7→8번의 대기 복귀에서 앞발 위치를 확인한다.
